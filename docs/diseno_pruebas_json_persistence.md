# Diseño de pruebas unitarias

**Requerimiento funcional / Historia de usuario:** RF-15 - Persistencia en formato JSON y RF-18 - Manejo de excepciones de persistencia: permitir almacenar y cargar en archivos JSON la información de los vehículos e incidentes registrados en el sistema utilizando estructuras propias (`LinkedList<T>`), lanzando `PersistenceException` ante archivos inexistentes o con contenido corrupto.

**Nombre del método:** saveVehicles(LinkedList<Vehicle> vehicles, Path filePath): void, loadVehicles(Path filePath): LinkedList<Vehicle>, saveIncidents(LinkedList<Incident> incidents, Path filePath): void, loadIncidents(Path filePath): LinkedList<Incident>

**Objetivo de la Prueba:** Verificar que `JsonPersistence` guarde y reconstruya fielmente listas enlazadas de vehículos e incidentes en archivos `.json` conservando todos sus atributos, y que capture errores de lectura o parseo lanzando la excepción personalizada `PersistenceException`.

| Arrange (Inicialización) | Act (Acción) | Assert (Verificar) |
|---|---|---|
| **Caso 1: Guardar y cargar vehículos en JSON conserva todos sus datos (ID, tipo, ubicación y estado).** | | |
| Instanciar `persistence = new JsonPersistence()`, definir `filePath = tempDir.resolve("vehicles.json")` y crear `vehicles` (`LinkedList<Vehicle>`) con `P-01` (`PATROL`, `"Zona Norte"`, `AVAILABLE`) y `A-01` (`AMBULANCE`, `"Zona Sur"`, `EN_ROUTE`). | `persistence.saveVehicles(vehicles, filePath); LinkedList<Vehicle> loaded = persistence.loadVehicles(filePath);` | `assertEquals(2, loaded.size()); assertEquals("P-01", loaded.get(0).getId()); assertEquals(VehicleType.PATROL, loaded.get(0).getType()); assertEquals("Zona Norte", loaded.get(0).getLocation()); assertEquals(VehicleStatus.AVAILABLE, loaded.get(0).getStatus()); assertEquals("A-01", loaded.get(1).getId()); assertEquals(VehicleStatus.EN_ROUTE, loaded.get(1).getStatus());` |
| **Caso 2: Guardar y cargar incidentes en JSON conserva su ID, tipo, ubicación, gravedad, estado, fechas y descripción.** | | |
| Instanciar `persistence = new JsonPersistence()`, definir `filePath = tempDir.resolve("incidents.json")` y crear `incidents` (`LinkedList<Incident>`) con `INC-001` (`FIRE`, `"Centro"`, `HIGH`, `PENDING`) e `INC-002` (`ACCIDENT`, `"Sur"`, `MEDIUM`, `RESOLVED`). | `persistence.saveIncidents(incidents, filePath); LinkedList<Incident> loaded = persistence.loadIncidents(filePath);` | `assertEquals(2, loaded.size()); assertEquals("INC-001", loaded.get(0).getId()); assertEquals(IncidentType.FIRE, loaded.get(0).getType()); assertEquals(Severity.HIGH, loaded.get(0).getSeverity()); assertEquals("INC-002", loaded.get(1).getId()); assertEquals(IncidentStatus.RESOLVED, loaded.get(1).getStatus()); assertNotNull(loaded.get(1).getResolvedAt());` |
| **Caso 3: Cargar vehículos o incidentes desde un archivo inexistente lanza `PersistenceException`.** | | |
| Instanciar `persistence = new JsonPersistence()` y definir `missingFile = tempDir.resolve("no_existe.json")`. | `persistence.loadVehicles(missingFile); persistence.loadIncidents(missingFile);` | `assertThrows(PersistenceException.class, () -> persistence.loadVehicles(missingFile)); assertThrows(PersistenceException.class, () -> persistence.loadIncidents(missingFile));` |
| **Caso 4: Cargar desde un archivo con JSON corrupto o malformado lanza `PersistenceException`.** | | |
| Instanciar `persistence = new JsonPersistence()`, crear `corruptedFile = tempDir.resolve("corrupt.json")` y escribir contenido inválido `"{ invalid json ["`. | `persistence.loadVehicles(corruptedFile); persistence.loadIncidents(corruptedFile);` | `assertThrows(PersistenceException.class, () -> persistence.loadVehicles(corruptedFile)); assertThrows(PersistenceException.class, () -> persistence.loadIncidents(corruptedFile));` |
